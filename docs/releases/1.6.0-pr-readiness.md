# TechCalc Pro 1.6.0 – PR- und Release-Readiness

Diese Unterlage dient der Abschlussprüfung des bestehenden Pull Requests für das Modul EN 378 Sicherheitscheck. Sie ersetzt nicht die CI-Gates und nicht die manuelle Browserfreigabe.

## Release-Ziel

Version 1.6.0 führt den EN 378 Sicherheitscheck für die Kernbewertung des Aufstellortes und der notwendigen Sicherheitsmaßnahmen ein.

Das Modul soll Planerinnen und Planern einen klaren Leitfaden geben:

- welche Anforderungen der gewählte Aufstellort aufweist,
- welche Sicherheitskomponenten erforderlich sind,
- welche Eingaben noch fehlen,
- welche Maßnahmen vor einer belastbaren Bewertung umzusetzen sind.

## Fachliche Modulgrenze

Enthalten sind sicherheitstechnische Bewertungen mit Bezug auf:

- importierten Anlagenstand aus dem F-Gase-Check,
- Kältemittel,
- Füllmenge,
- Raumvolumen,
- Aufstellort,
- Zugangsbereich,
- Nutzung,
- Lüftung,
- Maschinenraum,
- Detektion,
- Alarmierung,
- Abschaltung,
- alternative Vorkehrungen nach EN 378-1 C.3,
- Planer-Leitfaden und PDF-Bericht.

Nicht Bestandteil dieses Moduls sind:

- regulatorische Prüfungen der F-Gase-Verordnung,
- vollständige Geräteherstellerbewertung,
- vollständige Herstelleranforderungen aus EN 378-2 ohne direkten Bezug zum Aufstellraum,
- DIN EN ISO 5149-4-Bestandteile,
- Ersatz einer abschließenden Fachplanung.

## Architekturprüfung

Vor Merge zu bestätigen:

- Das Modul bleibt unter `js/modules/en-378-safety-check` gekapselt.
- Der Import aus dem F-Gase-Check erfolgt über versionierte Snapshots.
- Importierte Daten werden als Kopie übernommen.
- Es gibt keinen direkten Zugriff auf interne F-Gase-Modulzustände.
- Kältemitteldaten werden nur über die zentrale Kältemittelplattform bezogen.
- Die PDF-Ausgabe nutzt den zentralen Typed-DTO-Pfad.
- Das Speichern und Laden nutzt den bestehenden saved-record-Vertrag.
- Alle neuen Runtime-Dateien sind im Precache enthalten.
- Es entstehen keine zyklischen Abhängigkeiten.

## Fachlogikprüfung

Vor Merge zu bestätigen:

- Füllmengenbewertung nach EN 378-1 Anhang C wird berechnet.
- Alternative Vorkehrungen nach EN 378-1 C.3 werden nur bei Bedarf bewertet.
- Mindestanzahl alternativer Maßnahmen wird ausgewiesen.
- Öffnungsfläche und mechanischer Luftstrom werden nachvollziehbar ausgegeben.
- Aufstellort- und Maschinenraumanforderungen werden bewertet.
- Detektion, Alarmierung, Lüftung und Abschaltung werden als Maßnahmen geführt.
- Widersprüchliche Eingaben werden als Plausibilitätsproblem erkannt.
- Fehlende Eingaben werden als offene Angaben im Planer-Leitfaden ausgegeben.
- Erfüllte Prüfpunkte werden getrennt von offenen und nicht erfüllten Punkten dargestellt.

## UI- und PDF-Prüfung

Vor Merge zu bestätigen:

- Importierter Anlagenstand ist sichtbar und verständlich dargestellt.
- Die Aktion „Anlage importieren“ ist erreichbar.
- Bei mehreren gespeicherten F-Gase-Anlagen ist eine Auswahl möglich.
- Kontextabhängige Detailfelder reduzieren die Eingabeoberfläche.
- Alle sichtbaren Ausgaben sind deutsche Volltexte.
- Interne Feldnamen, Statuswerte und technische Schlüssel erscheinen nicht in UI oder PDF.
- Lange deutsche Texte werden ohne Einzelbuchstaben-Trennung dargestellt.
- C.3-Ergebnisse sind in der UI sichtbar.
- Plausibilitätsprüfung ist in UI und PDF sichtbar.
- PDF-Bericht enthält Eingaben, Bewertung, Maßnahmen, Leitfaden und Datenstand.

## Saved-record-Prüfung

Manuell im Browser zu prüfen:

1. F-Gase-Modul öffnen.
2. Anlage vollständig erfassen.
3. Anlage speichern.
4. EN 378 Sicherheitscheck öffnen.
5. Anlage importieren.
6. Bewertung mit Aufstellraumangaben durchführen.
7. EN-378-Bewertung speichern.
8. Gespeicherte EN-378-Bewertung laden.
9. Gespeicherte EN-378-Bewertung löschen.
10. Nach erneutem Laden prüfen, dass der gespeicherte Zustand vollständig wiederhergestellt wird.

## PDF-Smoke-Prüfung

Manuell im Browser zu prüfen:

1. EN-378-Bewertung aus importierter Anlage erzeugen.
2. PDF-Bericht erstellen.
3. Berichtszusammenfassung prüfen.
4. Importierten Anlagenstand prüfen.
5. Kältemittel-Sicherheitsdaten prüfen.
6. Füllmengenbewertung prüfen.
7. Alternative Vorkehrungen prüfen.
8. Plausibilitätsprüfung prüfen.
9. Planer-Leitfaden prüfen.
10. Datenstand prüfen.

## Automatische Gates

Vor Merge auszuführen beziehungsweise durch CI zu bestätigen:

```bash
npm run version:check
npm run precache:check
npm run audit:release-readiness
npm run audit:en378
npm run lint
npm test
npm run test:f-gases
npm run test:en378
npm run test:flooding
npm run test:integration
npm run build
npm run precache:check
```

Für den vollständigen Release-Gate-Lauf:

```bash
npm run release:verify
```

## Merge-Freigabe

Der PR ist releasebereit, wenn:

- CI vollständig grün ist,
- die manuelle Saved-record-Prüfung erfolgreich abgeschlossen ist,
- die manuelle PDF-Smoke-Prüfung erfolgreich abgeschlossen ist,
- keine internen Schlüssel in UI oder PDF sichtbar sind,
- der bestehende Pull Request final gereviewt wurde,
- der Merge in `main` freigegeben wurde.
