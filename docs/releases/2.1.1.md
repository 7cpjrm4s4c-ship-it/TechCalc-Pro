# TechCalc Pro 2.1.1

## Freigabe

TechCalc Pro 2.1.1 hebt die Version von 2.1.0 auf 2.1.1 an (Patch wegen veralteter Service-Worker-Caches bei bestehender Clients). Die Version ist über `package.json` als Single Source gesetzt und per `npm run version:sync` in `core/version.js`, `manifest.json`, `package-lock.json`, `core/app.js`, `modules/flooding-verification/reportAdapter.js`, `core/ux/releaseNotesController.js` und `index.html` synchronisiert. Der Service Worker trägt `CACHE_NAME = 'techcalc-pro-2.1.1'`; die `CACHE_REVISION` wird vom Precache-Werkzeug aus der ersten Überschrift der Release Notes abgeleitet (`2.1.1-unveroeffentlicht-bedienbarkeit-barrierefreiheit-und-performance`). Ein Produktionsdeploy wird durch diesen Repository-Stand allein nicht belegt.

## Umfang

Der Pull Request `fix/fgases-hermetic-exemptions` (PR #35) liefert die fachlichen F-Gases-Korrekturen und stellt sicher, dass der zentrale Select-Größenvertrag (einheitliche Select-Geometrie mit eigener SVG-Pfeilgrafik statt nativer OS-Steuerung) auch auf bereits geladenen Geräten ankommt:

- Neuer Service-Worker-Cache (`techcalc-pro-2.1.1`): Der `activate`-Handler löscht Altbestände und füllt den Cache neu; `TECHCALC_CACHE_UPDATED` meldet die neue Revision an alle Clients.
- Stylesheets (`.css`) werden netzwerk-first mit Cache-Fallback ausgeliefert; Offline bleibt die App vollständig aus dem Cache lauffähig.
- Service-Worker-Registrierung mit `updateViaCache: 'none'`, damit das Worker-Skript selbst nie aus dem Browser-HTTP-Cache stammt.
- Zentraler Select-Vertrag in `css/components-controls.css` (appearance: none, inline-SVG-Pfeil, rechtsbündig, einheitliche Geometrie), Light-Theme-Variante in `css/components-system.css` / `css/theme-light.css`.

## Qualität

- Release-Gates sind grün: `npm run version:sync` / `version:check`, `npm run precache:check`, `npm run audit:release-readiness`, `npm run lint`, `npm test`, `npm run test:f-gases`, `npm run test:integration`.
- Playwright-E2E: Layout-Vertrag (`module-layout-contract.spec.mjs`, inkl. Select-Größenvertrag) und Service-Worker-/Offline-Smoke (`phase37b-runtime-smoke.spec.mjs`) grün auf allen Browserprojekten.

## Risiko- und Architekturbewertung

Die Änderung bleibt auf Service-Worker-Auslieferung, Registrierungsoptionen, zentrale CSS-Verträge und Release-Metadaten (Version 2.1.1) begrenzt. Keine Änderungen an Prüf- oder Berechnungslogik, Kältemitteldatenbank oder Modul-Schemata. PR #35 wird nicht gemergt.
