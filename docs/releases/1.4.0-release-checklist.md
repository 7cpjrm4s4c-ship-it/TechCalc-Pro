# TechCalc Pro 1.4.0 – Release-Checkliste

## Automatisierte Freigabe

- [ ] `npm ci`
- [ ] `npm run release:verify`
- [ ] Keine fehlgeschlagenen Playwright-Projekte oder verworfenen visuellen Baselines
- [ ] Netlify Deploy Preview erfolgreich
- [ ] Pull Request konfliktfrei und mergebar

## Manuelle Modulabnahme

Für jedes registrierte Modul:

- [ ] Modul öffnet ohne Konsolenfehler
- [ ] Eingabefelder und Umschalter funktionieren
- [ ] Mindestens eine Berechnung durchgeführt
- [ ] Ergebnisdarstellung vollständig und ohne horizontalen Überlauf
- [ ] Card-Abstände vor und nach der Berechnung konsistent
- [ ] Speichern und erneutes Laden eines Datensatzes geprüft, sofern unterstützt
- [ ] PDF-Ausgabe fachlich und visuell geprüft, sofern unterstützt
