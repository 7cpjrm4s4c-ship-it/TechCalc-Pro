# Release Checklist

## Vor RC

- [ ] Alle Integration-Gates gruen.
- [ ] Precache/Service Worker synchron.
- [ ] Release Notes aktualisiert.
- [ ] Phase-Dokumentation abgeschlossen.
- [ ] Keine Root-Notizen oder temporären Phase-Artefakte.
- [ ] Keine Debug-Ausgaben oder sichtbaren Debug-Controls.

## RC-Regression

- [ ] Projektverwaltung
- [ ] PWA/Offline/Update
- [ ] Save/Edit/Selection
- [ ] Keyboard/Focus
- [ ] Mobile Input
- [ ] Theme Light/Dark/System
- [ ] PDF
- [ ] Zielgeraete

## Final Release

- [ ] Versionsnummer finalisiert.
- [ ] Neutral Deploy erzeugt.
- [ ] Development Netlify Full erzeugt.
- [ ] Release-Artefakte dokumentiert.
- [ ] Git-Tag gesetzt.
