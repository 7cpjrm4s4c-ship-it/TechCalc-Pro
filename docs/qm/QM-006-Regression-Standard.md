# QM-006 Regression Standard

Status: verbindlich ab Version 1.3.3-dev.7

## Regressionsumfang

Bei jeder fachlichen oder Plattformänderung sind mindestens zu prüfen:

- direkt betroffenes Modul,
- Referenzmodul mit vergleichbarem Workflow,
- Save/Load/Dirty-State,
- gespeicherte Records,
- Import/Export,
- PDF,
- Migration alter Projektdateien,
- Navigation und Modulwechsel,
- Mobile Input-Verhalten,
- Runtime-Konsole.

## Akzeptanz

Eine Regression gilt nur als abgeschlossen, wenn keine ungeklärten funktionalen Abweichungen offen sind. Bekannte externe Einschränkungen, etwa Spam-Einstufung externer Formulare, werden als Known Issue dokumentiert und nicht als App-Regression gewertet.
