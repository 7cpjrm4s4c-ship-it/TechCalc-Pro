# QM-012 Documentation Standard

Status: verbindlich ab Version 1.3.3-dev.7

## Dokumenttypen

- Phasen dokumentieren, was geändert wurde.
- ADRs dokumentieren, warum eine Architekturentscheidung getroffen wurde.
- Contracts dokumentieren, wie Schnittstellen und Module arbeiten.
- QM dokumentiert, welche Qualitätsregeln dauerhaft gelten.
- Release Notes dokumentieren, was ausgeliefert wird.
- Audits dokumentieren historische Nachweise und Baselines.

## Phasentemplate

Jede neue Phase enthält:

1. Ziel
2. Ausgangslage
3. Analyse
4. Design Review
5. Implementierung
6. Regression
7. Dokumentation
8. Ergebnis
9. Risiken
10. Betroffene Module
11. Referenzen
12. Folgephase

## Konsolidierungsregel

Ein Thema hat genau eine aktive Referenz. Historische Dokumente werden nicht gelöscht, aber als historisch markiert oder archiviert, wenn sie nicht mehr den aktuellen Standard definieren.
