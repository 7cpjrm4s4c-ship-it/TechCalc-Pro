# Architecture Decision Records

Status: Phase 43A structure baseline

ADRs dokumentieren wesentliche Architekturentscheidungen und deren Begruendung. Sie ersetzen keine Contracts, sondern erklaeren das Warum.

## Format

Jeder ADR enthaelt:

- Status
- Kontext
- Entscheidung
- Folgen
- Referenzen

## Beispielnamen

- `ADR-0001-central-theme-system.md`
- `ADR-0002-save-selection-contract.md`
- `ADR-0003-keyboard-contract.md`
- `ADR-0004-render-pipeline.md`
