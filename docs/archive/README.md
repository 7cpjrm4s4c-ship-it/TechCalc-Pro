# Documentation Archive

This directory keeps historical development artefacts that are useful for traceability but are no longer the active source of truth.

## Policy

- Active phase summaries live in `docs/phases/`.
- Stable engineering rules live in `docs/engineering/` and `docs/contracts/`.
- Architecture decisions live in `docs/adr/`.
- Detailed legacy patch notes, raw phase fragments and historical migration notes are archived here instead of staying in the repository root or top-level `docs/` folders.

Archived files must not be used to introduce new implementation rules unless the active contracts explicitly reference them.
